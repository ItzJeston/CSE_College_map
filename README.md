# 🗺️ CSE College Map

An interactive campus navigation system designed to help students, faculty, and visitors easily locate important places within the Computer Science department and navigate the campus efficiently.

This project provides a simple and user-friendly interface for exploring the campus map, making it easier for new students and visitors to find classrooms, laboratories, faculty cabins, administrative offices, and other important locations.

---

## 📌 Features

* 🏫 Interactive campus map
* 📍 Locate classrooms, labs, and faculty rooms
* 🧭 Easy navigation between locations
* 📱 Responsive interface
* ⚡ Fast and lightweight
* 🎯 Simple and intuitive user experience

## 💡 Motivation

Finding classrooms and department facilities can be confusing for new students and visitors. This project aims to provide a digital map that makes navigating the department simple and convenient.
